# 物語（ストーリー）の型 v0.1

既存のエクストラ（歴史・伝記・伝説）と地方決戦に、「章」と短い文を結びつける。エンジンは変えない（結果・リプレイ・バランスに影響しない）。

## データ（`packs/<国>/story.json`）
- `chapters[]`: `id`（章の id）、`kind`（normal / regional / extra）、`stageId`（結びつけるステージ）、`requires`（先に終える章の id。なければ最初から読める）、`title`（言語別）、`intro`（戦いの前）、`beforeBoss`（ボス登場の直前）、`outro`（勝ったあと）
- 文は `{speaker, text}`。`speaker` は `narrator`（語り）/ `boss`（ボスのせりふ）/ `note`（実在と伝説を分ける注記）。`text` は言語別で、**英語が必須**。訳がない言語は英語を出す
- 解説の並びは `chapters` の順。`requires` は、それより前の章だけを指せる

## 規則（Dart の `Story.validate` と `tools/validate_pack.py` が同じ）
- 章の id は重複しない。ステージは実在するもの（州・地方・エクストラ）
- 英語の題名・文が全部ある
- **伝説を元にしたエクストラ（`basis: legend`）の章は、`outro` に `note` を1つ以上入れる**（「何が実在で何が伝説か」を必ず書く）

## 進み具合（`StoryProgress`）
- 保存しない。クリアの記録（`BattleProgress`）から毎回計算する。章が終わった = 結びつくステージをどの難易度でもクリア。読める = `requires` の章を終えている
- `next`: 読めて、まだ終えていない最初の章
