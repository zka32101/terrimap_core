# 国ごとの特性・戦い方 土台 v0.1(2026-10-17)

## 目的
国ごとに「地図の形」だけでなく「戦い方の手触り」を変える。コアは**データの形と検証**だけを持ち、敵・施設・天候の実際の処理は、各ゲーム(タワーディフェンスは地理パズル王側)が `profile.json` を読んで実装する。

## 置き場所と形
`packs/<国>/profile.json`(任意。なければ従来どおり)。`RegionPack.parse(profileJson:)` で `pack.profile`(`CountryProfile`)から読む。検証は Dart(`PackValidator`)と Python(`tools/validate_pack.py`)で同じ規則。

| 項目 | 内容 | 規則 |
|---|---|---|
| style | 国の戦い方の型の識別子(UIの見出し・アイコン分け) | 空でない |
| summary | 言語→一言説明 | 任意 |
| enemyMix | 敵の種類→出現の重み | 種類は normal/speedy/armored/healer、合計1 |
| economy | startCoins / income / facilityCost の倍率(1.0が基準) | 0.5〜2.0 |
| pathLength | 進路の長さ | short / medium / long |
| signature | 国の目玉の仕組み(`id` をゲームが解釈) | id が空でない |
| regions | 地域id→ terrain / tags / facilityBonus / weatherEvent | 地域idは実在、terrain は sea/mountain/urban/agriculture/mixed(日本の既存の地形分類と同じ)、facilityBonus は1.0〜2.0 |

## 国ごとの案(仮。数値は未調整)
| | ドイツ(`engineered`) | 米国(`vast`) | 日本(既存の地理パズル王) |
|---|---|---|---|
| 手触り | 堅実・計画型 | 広大・多様な物量型 | 地形・天気・限定施設 |
| 敵の構成 | 装甲 40%・通常 35%・足速 15%・回復 10% | 通常 40%・足速 30%・装甲 20%・回復 10% | (既存) |
| 経済 | 収入やや高め(1.1) | 初期コインやや多め(1.2) | (既存) |
| 進路 | 中 | 長 | 県ごと |
| 目玉 | `federal_specialties`: 州ごとの得意分野で施設を強化。隣り合う州の得意分野がそろうと追加ボーナス | `weather_extremes`: 地域ごとに竜巻・ハリケーン・猛吹雪が起き、射程や敵の速さが一時的に変わる | 都道府県の限定施設・天気・相棒 |
| 地域の例 | バイエルン・バーデン＝ヴュルテンベルク=工業、ノルトライン＝ヴェストファーレン=鉱業、ニーダーザクセン=農業、ハンブルク・ブレーメン=港 | テキサス=エネルギー、カリフォルニア=工業、アイオワ=農業、フロリダ・ルイジアナ=ハリケーン、オクラホマ・カンザス=竜巻 | (既存) |

## ゲーム側の使い方(例)
- 敵の出現: `enemyMix` を重みに、ウェーブごとの敵の種類を決める
- 経済: 開始コイン・収入・施設の値段に `economy` の倍率を掛ける
- 地形: 地域の `terrain` を、既存の地形による補正(海・山・都市・農業)に渡す
- 施設: その地域に置く施設の効果に `facilityBonus` を掛ける
- 目玉: `signature.id` で分岐。`weatherEvent` を持つ地域でだけ、天候イベントを起こす

## 未決・未確認
- 数値(敵の割合・倍率・ボーナス)は仮。遊んで調整する
- 地域の特性(工業・鉱業・天候など)は一般的なイメージに基づく簡易な設定。事実の根拠は未検証で、ゲーム内の説明文にする前に確認する
- 目玉の仕組み(得意分野の連鎖・天候イベント)は、ゲーム側の設計と実装がまだ。コアにはゲームのロジックを置かない
- 日本の profile は未作成(日本packは国土地理院の規約確認待ち)。既存の地理パズル王の設定を、同じ形に移すかは未定
- `RegionTrait` の項目(terrain/tags/facilityBonus/weatherEvent)で足りるかは、実際に作ってみて決める
