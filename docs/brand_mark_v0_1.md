# Terrimap マーク v0.1（仮）

地球儀の面を経緯線のタイルに分け、橙のタイルで「T」を塗ったマーク。「地図が塗られていく」と「Terrimap の T」を1つで表す。

- 生成: `python3 tools/make_mark.py docs/brand [--bg indigo|teal|none]`（Pillow。結果は決定的）
- 出力（`docs/brand/`）: `mark.svg`、`mark_1024/512/192/48.png`（背景つき・藍）、`logo.svg` / `logo.png`（横長: マーク + Terrimap）
- 色は仮: 藍 (43,45,119)・橙 (244,163,0)・淡い陸地色 (232,241,242)。ブランドカラーが決まったら `COLORS` / `ORANGE` / `LAND` を差し替える
- 国別アイコン（`tools/make_icon.py`）とは別。国別アイコンの隅に添えるか、アプリ名ロゴとして使うかは未決

## 未確認・今後

- 北極に小さな点が残る、縁に小さな欠けがある（見た目の仕上げ）
- 実機のランチャー（丸・角丸の切り抜き）での見え方、アダプティブアイコン（前景/背景/単色）への分解は未対応
