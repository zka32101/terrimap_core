# Terrimap シリーズアイコン 共通設計 v0.1(2026-10-17)

## 方針
- シリーズ全体で同じ「型」を使い、国ごとに背景色と地図の形だけを替える
- 地図は terrimap_core の packs(Natural Earth)の実データから描く(形の正確さはデータに準ずる)
- 提出用は 1024×1024 の角丸なし正方形(角丸はストア側が自動でかける)

## 型(基本版 = 採用方向)
| 要素 | 内容 |
|---|---|
| 背景 | 国ごとの単色。DE=深い青緑 (15,76,92)、US=藍 (43,45,119)。今後の国は同系統の濃色で追加 |
| 地図 | 国全体を白っぽい色(DE (232,241,242)、US (240,236,224))で描き、境界線は背景色で細く抜く |
| 塗り | 数個の地域のみ全国共通のオレンジ (244,163,0) で塗る(「地図が塗られていく」を表す) |
| 地図の大きさ | 縦長(DE)は短辺基準で約68%、横長(US)は約84% |
| 除外 | 米国のアラスカ・ハワイは、アイコンでは判別しにくいので描かない |
| 塗る地域 | DE=バイエルン・ベルリン・ハンブルク、US=テキサス・カリフォルニア・ニューヨーク |

## タワーディフェンス版(試作・未決)
- 追加要素: 塔(黒っぽい城塔+橙の扉)、半透明の射程円、敵の進路(赤い点線)と敵(赤い丸)
- 課題: 米国版は進路が斜めで塔がテキサスを隠す。胸壁の3つ目がずれる。40pxでは細部が潰れる
- 判断待ち: 「地図クイズ」と「タワーディフェンス」のどちらを前面に出すか(塔を足すとクイズの印象は弱まる)

## 未確認・今後
- 色は仮。Terrimapのブランドカラーが決まれば背景色を揃える
- Apple / Google Play のアイコン規定(安全領域など)を提出前に確認
- ストア内の類似アイコンとの見分けは未確認
- Canvaでの仕上げ(文字入れ・ロゴ化)は、Canvaコネクターの再接続待ち
- 生成スクリプト: `tools/make_icon.py <de|us> <出力.png>`（Pillow。packs の実データから基本版を決定的に生成。`--label` で左下に国の略称バッジ（DE/US。下辺に国旗色の帯: DE=黒・赤・金、US=赤・白・青）、`--td` でタワーディフェンス版（試作: 塔・射程円・赤い点線の進路・敵）も生成）

## ブランド版（マーク・国の略称・うっすら国旗）
- 生成: `python3 tools/make_icon.py <de|us> <出力.png> --brand`（= `--label --mark --flag`。個別指定も可）
- 配置: 左上=国の略称バッジ（DE/US。下辺に国旗色の帯）、左下=Terrimap のマーク（白い丸バッジ。`tools/make_mark.py`）、背景全体=国旗をごく薄く（DE 10%・US 9%）。地図の塗る地域に重ならない
- `--label` だけのときは従来どおり左下（`--mark` と一緒のときだけ左上）
- 課題: 48px ではバッジが小さく略称もマークも判別できない。ランチャー用は地図だけ、ストア画像など大きい表示でブランド版を使う
- 未確認: DE の旗の金色が背景の青緑と混ざり、下の帯が緑がかって見える。実在の国旗をストア画像に使う際の規定は未確認
