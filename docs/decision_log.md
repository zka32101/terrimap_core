# 決定事項の記録(Terrimap)

新しいものを上に足す。「未決」は各設計書の末尾に残す。日付は 2026-10-17(会話内の決定を記録)。

## 国ごとの特性・見た目(設計: `country_profile_v0_1.md`)
- 国ごとに戦い方(敵の構成・経済・進路の長さ・国の目玉の仕組み)を変える。コアはデータの形と検証だけを持ち、敵・施設・天候の処理はゲーム側が実装する
- 敵の特性・攻撃性能(体力・速さ・拠点への被害・装甲・能力・敵の行動)と、施設の攻撃アクション(撃ち方と威力・射程・間隔)を国ごとに変える
- **国と州(地域)の特性を、できる限り反映する**。全地域に地形・特徴・背景を書き、施設ボーナス・天候・限定施設・敵の偏りは特徴のある地域に書く
- **背景・施設・敵の見た目も国ごとに変えていく**(今後の作業。素材は未作成)。敵は戦争や特定の歴史を連想させない
- 数値(割合・倍率・ボーナス)は仮。遊んで調整する

## アイコン(設計: `terrimap_icon_design_v0_1.md`)
- 基本の型は共通。国ごとに背景色と地図の形だけを替える。地図は packs の実データから `tools/make_icon.py` で生成
- 国名の略称は左下の白い角丸バッジ(案A)。バッジの下辺に国旗の色の帯(ドイツ=黒・赤・金、米国=赤・白・青)
- タワーディフェンス版は塔を大きく(約0.18×0.29)。塗った地域(橙)を隠さない配置にする
- 色は仮。ストアのアイコン規定と、似たアイコンとの見分けは未確認。Canva は接続済み(仕上げは Canva で行える)

## ドイツ版アプリ(`terrimap_ge` → 名称は `terrimap_de` に変更予定)
- 共通基盤(`terrimap_core`)の上に載せる。共通基盤を先に作る方針。既存アプリ(地理パズル王・社会コレ)への導入は後回し
- 課金: 無料は4州(16州の25%: バイエルン・ノルトライン＝ヴェストファーレン・バーデン＝ヴュルテンベルク・ベルリン)。買い切り(`unlock_all_states`、権利 `premium`)で全州解放＋広告なし。サブスクなし
- デイリーは全員同じ問題のため、無料でも全州から出す
- 広告は `app_common_kit`(ホームのバナー、クイズ・デイリー終了後の全画面広告。出題中は出さない)。子ども向けにはしない
- リポジトリ名 `terrimap_ge` は作成時の誤り。`terrimap_de` への変更は GitHub 上で手動(コードは `terrimap_de` に変更済み)
- 実機確認は未実施(チェックリスト: `device_check_de_v0_1.md`)
