## 国ごとの特性・見た目(設計: `country_profile_v0_1.md`)

- 敵の特性・攻撃性能(体力・速さ・拠点への被害・装甲・能力・敵の行動)と、施設の攻撃アクション(撃ち方と威力・射程・間隔)を国ごとに変える
- **国と州(地域)の特性を、できる限り反映する**。全地域に地形・特徴・背景を書き、施設ボーナス・天候・限定施設・敵の偏りは特徴のある地域に書く
- **背景・施設・敵の見た目も国ごとに変えていく**(今後の作業。素材は未作成)。敵は戦争や特定の歴史を連想させない
- 数値(割合・倍率・ボーナス)は仮。遊んで調整する

## 2026-10-17 復習モード（コア）
- `QuizEngine.generate` に `weights`（任意）を追加。省略時は従来と同じ出題（同seedで不変）。
- `reviewWeights(regionIds, mastered:, misses:)`: 未習得でミスが多いほど重く（1〜9）、習得済みは軽い（0.25〜1）。数値は仮。
- 重み付き抽選は Efraimidis–Spirakis 法（重複なし・決定的）。`Rng.nextDouble` を追加（`nextInt` の系列は不変）。
- 次: 連続記録（ストリーク）→ 難易度別シルエット出題。

## 2026-10-17 連続記録（コア）
- `DailyStreak`（current / best / lastDate）。日付は DailyChallenge と同じ UTC の yyyy-MM-dd。
- 同日の再記録・過去日付は変えない。1日空いたら 1 に戻り、最長は残す。表示用は `currentOn(today)`（昨日まで継続中なら表示、2日以上空いたら0）。
- 保存は `toJson`/`fromJson` をアプリ側が行う。`ProgressStore` のインターフェースは変えない（既存実装を壊さない）。
- 端末の日付改ざん・タイムゾーン差による不公平は未対策（UTC基準で統一）。

## 2026-10-17 難易度別シルエット出題（コア）
- `Difficulty`（easy/normal/hard）と `regionsForDifficulty(pack, d)`: 描画面積の降順で3分割（大=easy／中=normal／小=hard）。重ならず合わせて全地域。`QuizEngine.generate(pool: ...)` にそのまま渡す。
- 面積は国ごとの設定なしで、パックの投影から自動計算（ドイツ・米国で確認）。
- 注意: 米国のアラスカ・ハワイは地図上のインセット（縮小）の面積で測るため、実際の大きさより難しい側に入る。気になる場合はパック側で面積を上書きできるようにする（未実装）。

## 2026-10-17 地図のブラウザ確認（Playwright）
- `demo/`（Flutter Web の小さなデモ）＋ `demo/run_e2e.sh`（ビルド→配信→Playwright）。地図（`RegionMapView`）だけを実ブラウザ（Chromium）で動かし、3つの画面サイズ（320×480 / 390×700 / 412×800）で、(1)読み込みエラーなし (2)拡大ボタン（2倍・12倍で止まる・リセット）(3)各州を実際のクリックで選べるか（DE: BY/HB/HH/BE、US: TX/CA と極小州 RI/DC/DE/NJ/CT/NH/VT/MA/MD。必要なら拡大・移動）を確認。スクリーンショットは `demo/e2e/out/`（git管理外）。CIには入れない（重いため手動）。
- 結果: 全部OK。極小州は 1〜2倍で、代表点のクリックで選べた（最小タップ半径の補助つき）。
- 見つけて直した不具合: 拡大すると地図の境界線が太くなる（12倍で約7px）→ 線の太さを拡大率で割って細いままにした。`RegionMapView` に任意の `controller`（拡大状態を外から読む/操作する）を追加。
- できないこと: 実機での指の押しやすさ、端末ごとの見え方、広告・課金は確認しない。Flutter Web で Semantics（アクセシビリティ）を有効にすると、座標つきのタップが届かなくなるため、このデモでは使わない（スクリーンリーダーでの地図操作は別途の課題）。

## 2026-10-17 ゲーム設計レビューと追加の決定（設計書 v0.4）
- レビューの指摘: 学習とバトルがつながっていない／要素が多い／対象年齢のぶれ。
- 採用:
  1. **州の形が盤面**（形の外のマスは使えない）、**拠点は州都の位置**、**敵は実際に隣り合う州の方向から来る**（入口に隣の州名。後半・hard・エクストラは入口が増える）。→ 州の形・州都・隣接を、進路を覚えるだけで学べる。パックに `capitalPos`・`neighbors`・`coast` を追加（`capitalPos` は州の形の中にあることを検証で守る）。

## 2026-10-17 M0.5 パックの追加データ（州都の位置・隣接）
- `regions.json` に `capitalPos`（`{x, y}`。`geo.geojson` と同じ座標系）と `neighbors`（隣り合う地域のid、昇順）を追加。ドイツ16州・米国51州。`coast` は、M1で盤面の縁から求められるため、パックには持たない。
