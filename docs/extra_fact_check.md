## 確認の手順
1. 下の表の「確認先」で、各主張を1つずつ確かめる(百科事典1つだけに頼らず、公的機関・図書館・原典の版元など1次に近い資料を1つ以上)。
2. 食い違いがあれば、`packs/<国>/profile.json` の `fact`(英語)を直し、`python3 tools/validate_pack.py packs/<国>` と `flutter test` を通す。
3. アプリ側の `packs/<国>/profile.json` を同期する(アプリのPRで)。翻訳は、**確認が終わってから**する。
