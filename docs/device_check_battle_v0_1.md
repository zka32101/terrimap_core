# バトル 実機確認チェックリスト v0.1

作成日: 2026-10-18 / 対象: `terrimap_ge`（ドイツ版）・`terrimap_us`（米国版）のバトル・今日のバトル・リプレイ・地方決戦・エクストラ。
地図クイズ・課金・広告・同意の確認は `device_check_de_v0_1.md` を先に（そちらは変わらず必要）。
前提: ここまでは `flutter analyze` クリーン・自動テスト通過まで。**バトルは実機・エミュレータで一度も動かしていない**。ここには実機でしか確かめられないものだけを書く。

## 0. 準備
- 端末: ①低スペック（RAM 2〜3GB）②小さい画面（幅360dp前後）③大きい画面／タブレット ④可能なら iPhone と Android の両方。
- ビルドは「疑似購入」の開発ビルドと、「本物のテスト購入」のビルドの両方（買い切りの有無でロックが変わる）。
- 日付を変えて試すには、端末の日付を変える（今日のバトルは UTC の日付で決まる。日本では朝9時に切り替わる）。
- 記録する表（§10）を印刷または別画面に開いておく。

## 1. 盤面と操作（最優先）
| 確認 | 合格の目安 |
|---|---|
| 設置枠をタップ→施設を選んで置く | 1回のタップで枠が選べる。隣の枠を誤って選ばない（小さい画面でも） |
| 置いた施設をタップ→強化・撤去・修理 | ボタンが指で押せる大きさ。押した結果がすぐ見える |
| 敵・施設・攻撃の表示 | 敵と施設が識別できる。重なっても見失わない |
| 速度（×1/×2）・一時停止 | 切り替えが即座。一時停止中は敵が止まり、操作はできる |
| 盤面の縦横比（州ごとに違う形） | 横長・縦長の州（例: DE-SH、US-FL、US-HI）でも盤面が画面に収まり、隅が切れない |
| 文字サイズを最大にする | HUD（波・HP・コイン）、ボタンが崩れない（折り返される） |
| 画面を回転する | 崩れない。バトルの進行が壊れない（縦固定ならそのままでよい） |

### 画像（試作・ドイツ版）
- 背景: アルプス（バイエルン）と都市（ベルリン）の背景が出る。横長の背景はぼかして遠景になり、盤面が地面の上に見える（空に浮いて見えない）。ほかの州は図形の背景のまま。
- 施設6種・敵4種・ボス1体（ローレライ）の画像が出る。図形に戻る要素（限定施設など）があっても、崩れない。
- 見やすさ: 施設・敵の大きさ、設置枠（白い枠）が背景の上で見える、敵のHPバーが見える、拠点と進路が分かる。
- 画風: 施設と敵・ボスの絵柄が、そろって見えるか（そろわない場合は、どれが浮くか記録）。
- ローレライ: 人物の描写が強すぎないか（docs の「人の顔の細部は描かない」との整合）。

## 3. 中断と復帰（壊れやすい）
- バトル中にホームボタン→戻る: 時間が止まっている（敵が進みすぎていない）。アプリが落ちない。
- バトル中に電話・通知・別アプリ→戻る: 同上。クイズのダイアログが出ている最中でも壊れない。
- バトル中に端末をロック→解除。
- バトル中に「戻る」操作（Android の戻るボタン／iOS のスワイプ）: 確認なしで抜けても問題ない（記録されない）。結果ダイアログの最中も壊れない。
- アプリを強制終了→再起動: **クリア記録**（州の緑のチェック、地方決戦・エクストラの解放状況）と**今日のバトルの結果**が残っている。バトル中の進行は戻らなくてよい。

## 4. クイズ連動（バトル中）
- 準備中のスキル選択: 問題に正解すると3つから選べる。不正解だと3つのうち1つが自動で決まる。
- 修理: 正解で無料、不正解でコイン。hard の時間制限（10秒）が、実際に短く感じられるか。
- 設定でクイズ連動をオフ: スキルが3つから選べ、修理はコインだけ。
- 問題の出題元が、ここで遊んでいる州の隣の州などから出ている（地方決戦では地方の州から）。
- 問題画面を出している間、バトルの時間が止まっている。
- **一時バフ**: 正解すると、上部に「⚡ +20% 10s」のチップが出て、10秒で消える。10秒以内にもう一度正解すると +30% に上がる（最大 +50%）。不正解ではバフが付かず、ペナルティもない。
- **復習**: 間違えた州が、次のバトルのクイズで出やすくなる（何度か遊んで、同じ州が繰り返し出るか）。習得済みの州は出にくい。毎日のバトルでは偏らない（全員同じ条件）。

## 5. 天候・季節・ボス・スキルの見え方
- 天候の予告→開始→終了で、メッセージが出る。何が変わったか（射程・速さ・威力）が、画面で分かるか。
- 季節のチップが、エクストラでは波ごとに変わる。
- ボスのスキル（加速・回復・召喚・施設の停止）が起きたとき、メッセージが出る。
- 色だけに頼らず、文言でも分かる（色覚への配慮）。
- 体感: 天候のタイミングで慌てすぎない／退屈にならない。
- **天候の見た目**: 嵐・ハリケーン=雨、吹雪=雪、熱気=オレンジの色とゆらめき、山火事=火の粉、洪水=下から水、竜巻=渦、地震=土ぼこりと盤面のゆれ。盤面・施設・敵が見えにくくならないか。ゆれで酔わないか。低スペックの端末でカクつかないか。

## 6. 州・地方決戦・エクストラ
- 選択画面: 州／地方決戦／エクストラ（ドイツ版は4地方・3話、米国版も4地方・3話）。
- 無料の間: 無料の州だけ遊べる。地方決戦・エクストラは「全州解放が必要」と出て、タップで購入案内。
- 購入後: 地方決戦は「その地方の州の過半数クリア」で解放、エクストラは「全州を hard でクリア」で解放。条件の文言が分かりやすい。
- エクストラの説明: あらすじ・事実の注記・ボスが読める。**注記が実際の事実と合っているか**（`docs/extra_fact_check.md`）。
- 限定施設: 複数あるステージで、順に置ける。名前が各言語で出る。

## 7. 今日のバトル・共有・挑戦・リプレイ
- 今日のバトル: 同じ日付で、2台の端末が**同じ州・同じ難易度**になる（UTC）。無料の間は無料の州だけ。
- 終えた日はカードが完了表示になり、タップでリプレイが見られる。翌日（UTC）に新しい問題になる。
- **連続記録**: 毎日のバトルを終えると、カードに「🔥n」が出る。翌日（UTC）も終えると n が増え、1日空けても昨日までは表示が残り、2日以上空くと消える。アプリを閉じて開いても残る。
- 共有: 「共有」でコピーした文字列を、メッセージアプリに貼ると、波ごとの🟩🟥⬛と拠点HPが崩れず見える。絵文字が環境で化けない。
- 挑戦コード: 1台でコピー→もう1台で貼る→「検証済み」と出て遊べる。1文字壊すと「検証できない」と出る。長いコードがメッセージアプリで途切れない。
- リプレイ: 再生・一時停止・×1/2/4・最初から・最後まで飛ばす。**最後に「Verified」が出る**。端末を変えても（性能が違っても）同じ結果になる。
- 別の端末（OS・CPU が違う）で再生しても、結果が一致する（浮動小数点の差が出ないか）。ここは**必ず2機種以上**で。

## 7b. 図鑑・招待・実績・今週のチャレンジ・レビュー依頼・設定
- **図鑑**: 州をクリアすると、ステージ選択の図鑑ボタンに「NEW」のバッジが出る。開くとその州の名所カードが解放され、バッジが消える。未解放は「？」と鍵で、解放条件の州名が出る。カードの文字がはみ出さない（長い名所名・長い言語）。
- **ボス紹介カード**: エクストラのボスが出たときに、名前と事実の注記が1回だけ出て、数秒で消える。盤面の操作をじゃましない。
- **友だち招待**: 州をロングタップ→招待がコピーされ、メッセージアプリに貼って崩れない。もう1台で貼ると、ステージ・難易度・相手の結果が出て、同じステージで遊べる。壊した招待は「使えない」と出る。解放していないステージは遊べない旨が出る。
- **実績**: ステージ選択のトロフィーのボタンから開く。クリア・連続日数・図鑑で達成が増え、新しい達成にバッジと「NEW」が出て、開くと消える。未達成はグレーで進捗が出る。アプリのデータ削除で全て未達成に戻る。
- **今週のチャレンジ**: 同じ週（UTC・月曜はじまり）は、2台で**同じステージ・難易度**になる。無料の間は無料の州だけ。1回遊ぶと結果が出て、タップしても入れず、リトライも出ない。共有ボタンでコピーした招待を、もう1台で貼ると同じステージで遊べる。翌週（月曜UTC）に新しくなる。
- **レビュー依頼**: 初回起動から7日以上・勝利3回以上のあとに、勝って戻ると「楽しんでいますか？」が出る（負けた直後・戦闘中・リトライでは出ない）。「はい」でストアのレビュー画面（クローズドテストでは出ないことがある）、「いいえ」で何も出ず、しばらく出ない。
- **設定**: 表示モード（システム／ライト／ダーク）が全体に効いて、再起動しても残る。言語を変えると文言が変わる。データ削除は確認のあと、進捗・設定が初期に戻り、購入は残る。

## 7c. 復習・統計・チュートリアル・記録・名所・音・通知

- **復習**: 間違えた州があるとホームに「復習」が出て、その州だけが出題される。0件になるとボタンが消える
- **統計**: ホーム右上のグラフから開ける。クイズ・バトル・連続日数・図鑑・実績の数字が、遊んだ内容と合う
- **記録（勝敗・プレイ時間）**: バトルの勝ち・負けが数えられ、勝率が出る。ポーズ中の時間は入らない。途中でやめた時間も入る
- **チュートリアル**: 初回バトルで案内が出る。設定の「もう一度見る」で戻せる。小さい画面でも案内が切れない
- **今日の名所**: ホームに日替わりの名所（画像・名前・州）。日付が変わると変わる。画像がなくてもアイコンで崩れない
- **名所クイズ**: ホームの「名所クイズ」で10問、名所の画像が出る。答えると州が示される。結果に正答率と、間違えた名所が出る
- **図鑑の詳細**: カードをタップすると大きな画像・名前・州が出る（未解放は開かない）
- **効果音**: 正解・不正解・クリア・敗北で鳴る。設定でオフにすると鳴らない。マナーモードで鳴らないこと
- **BGM**: 設定でオンにすると流れ続ける（ループの継ぎ目が気にならないか）。ボス戦では曲が変わる。オフで止まる
- **毎日のリマインダー**: 設定でオン→許可ダイアログ→指定した時刻に1日1回届く。許可しないとオフのまま。オフで届かなくなる。端末再起動後も届く
- **ストリーク救済**: 連続中で今日のチャレンジがまだの日だけ、夕方に届く。チャレンジを済ませると届かない

## 11. 見つけたら必ず報告してほしいもの
- バトルが固まる・落ちる（再現手順と端末を添えて）
- リプレイが「Verified」にならない（別端末で遊んだ結果と再生が違う）。これはエンジンの決定性に関わるので最優先
- 解放条件が文言どおりにならない（買い切りなのに地方決戦が開かない、など）
- 勝てなさすぎる／簡単すぎる（easy で連敗、hard が簡単など）。体感の記録を数字で（何回中何回勝てたか）
