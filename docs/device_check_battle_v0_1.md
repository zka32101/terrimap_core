# バトル 実機確認チェックリスト v0.1

作成日: 2026-10-18 / 対象: `terrimap_ge`（ドイツ版）・`terrimap_us`（米国版）のバトル・今日のバトル・リプレイ・地方決戦・エクストラ。
地図クイズ・課金・広告・同意の確認は `device_check_de_v0_1.md` を先に（そちらは変わらず必要）。
前提: ここまでは `flutter analyze` クリーン・自動テスト通過まで。**バトルは実機・エミュレータで一度も動かしていない**。ここには実機でしか確かめられないものだけを書く。

## 0. 準備
- 端末: ①低スペック（RAM 2〜3GB）②小さい画面（幅360dp前後）③大きい画面／タブレット ④可能なら iPhone と Android の両方。
- ビルドは「疑似購入」の開発ビルドと、「本物のテスト購入」のビルドの両方（買い切りの有無でロックが変わる）。
- 日付を変えて試すには、端末の日付を変える（今日のバトルは UTC の日付で決まる。日本では朝9時に切り替わる）。
- 記録する表（§10）を印刷または別画面に開いておく。

## 1. 盤面と操作（最優先）
| 確認 | 合格の目安 |
|---|---|
| 設置枠をタップ→施設を選んで置く | 1回のタップで枠が選べる。隣の枠を誤って選ばない（小さい画面でも） |
| 置いた施設をタップ→強化・撤去・修理 | ボタンが指で押せる大きさ。押した結果がすぐ見える |
| 敵・施設・攻撃の表示 | 敵と施設が識別できる。重なっても見失わない |
| 速度（×1/×2）・一時停止 | 切り替えが即座。一時停止中は敵が止まり、操作はできる |
| 盤面の縦横比（州ごとに違う形） | 横長・縦長の州（例: DE-SH、US-FL、US-HI）でも盤面が画面に収まり、隅が切れない |
| 文字サイズを最大にする | HUD（波・HP・コイン）、ボタンが崩れない（折り返される） |
| 画面を回転する | 崩れない。バトルの進行が壊れない（縦固定ならそのままでよい） |

## 2. 性能（実測する）
| 確認 | 合格の目安 | 記録 |
|---|---|---|
| フレームレート | 敵が多い波・天候中・×2速でも 55fps 以上、カクつきが気にならない | DevTools のパフォーマンス／`flutter run --profile` |
| 最も重い場面 | 米国のエクストラ（10波）、hard、ボス＋召喚、天候中 | 最悪fpsを記録 |

| 起動からバトル開始まで | 州を選んでから盤面が出るまで 2 秒以内（地方決戦・エクストラ含む） | 秒 |

## 3. 中断と復帰（壊れやすい）
- バトル中にホームボタン→戻る: 時間が止まっている（敵が進みすぎていない）。アプリが落ちない。
- バトル中に電話・通知・別アプリ→戻る: 同上。クイズのダイアログが出ている最中でも壊れない。
- バトル中に端末をロック→解除。
- バトル中に「戻る」操作（Android の戻るボタン／iOS のスワイプ）: 確認なしで抜けても問題ない（記録されない）。結果ダイアログの最中も壊れない。
- アプリを強制終了→再起動: **クリア記録**（州の緑のチェック、地方決戦・エクストラの解放状況）と**今日のバトルの結果**が残っている。バトル中の進行は戻らなくてよい。

## 4. クイズ連動（バトル中）
- 準備中のスキル選択: 問題に正解すると3つから選べる。不正解だと3つのうち1つが自動で決まる。
- 修理: 正解で無料、不正解でコイン。hard の時間制限（10秒）が、実際に短く感じられるか。
- 設定でクイズ連動をオフ: スキルが3つから選べ、修理はコインだけ。
- 問題の出題元が、ここで遊んでいる州の隣の州などから出ている（地方決戦では地方の州から）。
- 問題画面を出している間、バトルの時間が止まっている。

## 5. 天候・季節・ボス・スキルの見え方
- 天候の予告→開始→終了で、メッセージが出る。何が変わったか（射程・速さ・威力）が、画面で分かるか。
- 季節のチップが、エクストラでは波ごとに変わる。
- ボスのスキル（加速・回復・召喚・施設の停止）が起きたとき、メッセージが出る。
- 色だけに頼らず、文言でも分かる（色覚への配慮）。
- 体感: 天候のタイミングで慌てすぎない／退屈にならない。

## 6. 州・地方決戦・エクストラ
- 選択画面: 州／地方決戦／エクストラ（ドイツ版は4地方・3話、米国版も4地方・3話）。
- 無料の間: 無料の州だけ遊べる。地方決戦・エクストラは「全州解放が必要」と出て、タップで購入案内。
- 購入後: 地方決戦は「その地方の州の過半数クリア」で解放、エクストラは「全州を hard でクリア」で解放。条件の文言が分かりやすい。
- エクストラの説明: あらすじ・事実の注記・ボスが読める。**注記が実際の事実と合っているか**（`docs/extra_fact_check.md`）。
- 限定施設: 複数あるステージで、順に置ける。名前が各言語で出る。

## 7. 今日のバトル・共有・挑戦・リプレイ
- 今日のバトル: 同じ日付で、2台の端末が**同じ州・同じ難易度**になる（UTC）。無料の間は無料の州だけ。
- 終えた日はカードが完了表示になり、タップでリプレイが見られる。翌日（UTC）に新しい問題になる。
- 共有: 「共有」でコピーした文字列を、メッセージアプリに貼ると、波ごとの🟩🟥⬛と拠点HPが崩れず見える。絵文字が環境で化けない。
- 挑戦コード: 1台でコピー→もう1台で貼る→「検証済み」と出て遊べる。1文字壊すと「検証できない」と出る。長いコードがメッセージアプリで途切れない。
- リプレイ: 再生・一時停止・×1/2/4・最初から・最後まで飛ばす。**最後に「Verified」が出る**。端末を変えても（性能が違っても）同じ結果になる。
- 別の端末（OS・CPU が違う）で再生しても、結果が一致する（浮動小数点の差が出ないか）。ここは**必ず2機種以上**で。

## 8. 言語・表示
- 11言語のうち、翻訳が入った言語で: バトルの文言、限定施設名、天候名、結果ダイアログが、はみ出さず読める。
- 長い言語（ドイツ語、フィンランド語系ではなくても）でボタンが2行になっても崩れない。

- ダークモード: 盤面・HUD・ダイアログが読める。

## 11. 見つけたら必ず報告してほしいもの
- バトルが固まる・落ちる（再現手順と端末を添えて）
- リプレイが「Verified」にならない（別端末で遊んだ結果と再生が違う）。これはエンジンの決定性に関わるので最優先
