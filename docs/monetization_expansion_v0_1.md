# 追加課金の設計 v0.1

現状: 買い切り1つ(`unlock_all_states` = 権利 `premium`)で「全州解放+広告なし」。無料は4州(DE)/一部(US)。
地方決戦・エクストラは、無料でない州のクリアが条件なので、実質は買い切りの中身。広告は AdMob(バナー/インタースティシャル/リワード)。

## 方針(守ること)
- **勝敗に直結する強化は売らない**(体力・攻撃・資金など)。リプレイ・バランス・ストア規約の検証が重くなり、評価も下がりやすい。
- **既存の買い切りを買った人の中身は減らさない**。新しい商品は「足す」だけ。
- 子ども向けにしない設定(COPPA/GDPR-K 回避)は変えない。ガチャ・ランダム型の課金は入れない。
- ストア掲載文は `docs/aso-rules.md` に従う。価格はストアの価格帯から選ぶ(下は仮)。

## 決定(ユーザー)
- **エクストラパック(エクストラの別売り)は作らない。** エクストラは今までどおり、買い切り(全州解放)の中身。
- 第1弾の広告削除 `remove_ads` は実装済み(ge #65 / us #58)。

## キット(app_common_kit)の変更案
- いまの `EntitlementState` は `hasNoAds` / `hasPremium` だけ。2〜5 を売るには、**任意の権利ID集合**(`Set<String> extra`)を足す。
  - `RevenueCatEntitlementService` は、有効な権利のうち既知のID以外を `extra` に入れる。
  - `FakeEntitlementService` も同じ形にする(開発・テスト用)。
  - 互換: 既存の2つのフラグ・`adsHidden` はそのまま。
- 他アプリへの影響を避けるため、追加のみ(破壊的変更なし)にする。キットのPRを先に出し、マージ後にアプリ側。

## アプリ側
- 解放シート(`unlock_sheet.dart`)を、商品ごとの一覧に拡張。購入の復元は1つのボタンで全部。
- 見た目: 選択状態はアプリ側の保存(購入していない見た目は選べない)。リプレイ・対戦のエンジンには影響させない。

## 検証
- 購入前後で、リプレイ・バランステスト(ボット)の結果が変わらないこと(見た目の追加でエンジンのルールは変えない)。
- 復元: 別端末・再インストールで、全商品が戻ること。
- 権利が無いのに解放される経路がないこと(招待・共有リンクを含む)。
