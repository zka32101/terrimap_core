# 深い知識のクイズ v0.1

州当て(地図・州名・州都・形・隣接)と名所のほかに、**特産品・名物・企業・行事・自然**を出題する。

## 問題
- 種類 `QuestionType.knowledgeOf`: 「この名物はどの州のもの？」を4択で答える。正解はその題材の州、誤答は他の州3つ。
- 題材は `packs/<国>/facts.json` の `knowledge`(名所の `landmarks` と同じ形)。州ごとに1つ以上(DE 31 / US 66。全州をカバー)。
- 題材のない州は、地図から州名の問題になる(名所と同じ)。
- 通常のクイズ(`QuestionType.values`)に混ざる。**バトル中のクイズの種類は変えない**(出題の並びが変わると、保存済みのリプレイが再現できなくなるため)。

## データ(`knowledge` の1件)
| 項目 | 内容 |
|---|---|
| `id` | 英小文字とアンダースコア。国の中で一意 |
| `region` | 州のid(1つ)。その州の名物・企業・行事など、**他の州と取り違えにくい**ものを選ぶ |
| `kind` | `food`(食べ物・飲み物)／`product`(製品・企業)／`culture`(行事・文化)／`nature`(自然)。問題文を変える |
| `name` | `en` は必須。DE は `de`・`ja`、US は `ja`。他の言語は英語で表示 |
| `check` / `source` | `unchecked` のまま追加し、確認したら `checked` と出典に書き換える |

## 選び方の方針(誤答が紛らわしくならないように)
- 発祥や所在に争いのあるものは避ける(複数の州・国が名乗るもの)。
- 企業は本社や創業の地が明確なもの。商標は名称だけを使い、ロゴは使わない。
- 州の名前をそのまま含む題材(「Maryland blue crab」など)は答えが分かりやすいが、地域の特産としては自然なので残す。

## 事実の確認が要るもの(`check: unchecked`)
全件が未確認。特に次は、確認してから公開する。
- `DE`: 「ベックスビール=ブレーメン」「ミューリッツ湖=メクレンブルク=フォアポンメルン州」「ニュルブルクリンク=ラインラント=プファルツ州」「ディッベラベス=ザールラント」「ヴォルフスブルクのフォルクスワーゲン=ニーダーザクセン州」
- `US`: 「ペプシ=ノースカロライナ(ニューバーン)」「アーバーデーの発祥=ネブラスカ」「ミシシッピのデルタ・ブルース」「アラバマ・ホワイトソース」「ボーイング=ワシントン州(エバレット)」「Mall of America=ミネソタ」「First state=デラウェア」「ロズウェルのUFO=ニューメキシコ」

## アプリ側
- 通常のクイズに混ざる。専用のボタン「ごちそう・名物クイズ」(食べ物・製品・行事・自然だけを出す)をホームに置く。
- 問題文は種類ごと(食べ物／製品／行事・文化／自然)。答えたあと、題材の名前と正解の州を出す。
