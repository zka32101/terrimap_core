# ドイツ版 実機確認チェックリスト v0.1

作成日: 2026-10-17 / 対象: `terrimap_ge`（ドイツ版、仮名 State Master – Germany）
前提: コードは `flutter analyze` クリーン・自動テスト通過まで。**実機・エミュレータでは一度も動かしていない**。ここに書いた項目は、実機でしか確かめられないもの。

## 0. 自動テストで確認済み（実機では再確認のみ）
- 16州すべてが、ズーム1倍・実際のタップ操作で押せる（画面 320×480 / 390×600 / 412×700。`test/tap_widget_test.dart`）
- 描画が小さい州（ズーム1倍・390×600 の短辺）: ベルリン 20.8px・ブレーメン 20.1px・ハンブルク 20.9px。最小タップ半径（18px）で補っている
- 無料4州・解放・広告の出し分け・進捗の保存（`terrimap_ge` のテスト）

## 1. 地図の操作（最優先）
| 確認 | 合格の目安 |
|---|---|
| ベルリン・ブレーメン・ハンブルクを指でタップ | 3回続けて押して、隣の州に当たらない |
| ブランデンブルク（ベルリンを囲む州）の端をタップ | ベルリンではなくブランデンブルクになる |
| ピンチで拡大して都市州をタップ | 拡大するほど押しやすい。戻す（縮小）も自然 |
| 拡大中にパン（ドラッグ）して、離した時にタップ扱いにならない | 誤って回答にならない |
| 小さい端末（幅320dp相当）と大きい端末 | 地図が画面に収まり、隅が切れない |
| 文字サイズを最大にする | ボタン・見出しが崩れない |
| 地図タップ問題（locateOnMap）で、間違えた州が赤・正解が緑になる | 色だけでなく文言（正解／不正解）も出る |

## 2. クイズ・デイリー
- 5種類（地図タップ／地図から州名／州名から州都／州都から州名／形当て）が、それぞれ出る
- 形当てのシルエットが、全16州で正しい形に見える（飛び地・島が欠けない）
- デイリーが2回目に同じ問題になる（同じ日・同じ端末）。日付が変わると変わる（UTC基準なので、日本時間の朝9時に切り替わる点に注意）
- 結果の共有文（🟩🟥）がコピーできる
- アプリを終了して再起動しても、進捗（緑・赤、称号）が残る

## 3. 課金（テスト用の購入環境で）
- 無料: 4州（バイエルン・ノルトライン＝ヴェストファーレン・バーデン＝ヴュルテンベルク・ベルリン）だけ色がつき、他はグレーで、タップすると解放の案内が出る
- 購入 → 全州の色が戻り、バナー広告が消える。解放ボタンも消える
- 購入の復元（別端末・再インストール後）
- 購入の取り消し・失敗時に、アプリが壊れない
- 本番キー未設定の開発ビルドは疑似購入（キーを渡したビルドで、本物の購入が動く）

## 4. 広告・同意（EU圏の設定で）
- 初回起動でUMPの同意画面が出る（テスト端末のIDをAdMobに登録して確認）
- 同意しない／管理するを選んでも、アプリは使える
- バナーはホームだけ。出題中・解説中に全画面広告が出ない
- 全画面広告は、クイズ・デイリー終了後だけ。最短3分・1日5回まで
- iOS: 追跡許可（ATT）の文言（今は英語の仮文）と、許可しない場合の動き
- リリースビルドで、テスト広告IDが残っていない（キットが例外で止める）

## 5. 言語・表示
- 端末がドイツ語 → ドイツ語で起動する／それ以外 → 英語
- 設定で言語を切り替えると、州名・州都名・購入欄の文言も変わる
- 設定に「Made with Natural Earth」の出典が出ている
- ダークモードで、地図と文字が読める（今は専用の配色を作っていないので、崩れていれば要対応）
